# IMDb Data Analysis for RSVP Movies (SQL Project)

## Project Overview
This project involves analyzing an IMDb movie dataset using SQL to derive actionable insights for RSVP Movies, a film production company planning a global release. The goal was to support data-driven decision-making by identifying trends in genres, ratings, production houses, and audience preferences.

---

## Objectives
- Analyze movie trends over recent years
- Identify top-performing genres and high-rated movies
- Evaluate directors, actors, and production companies
- Generate insights to support global movie production strategy

---

## Tools & Technologies
- SQL (MySQL Workbench)
- IMDb Dataset

---

## Key Analysis Performed
- Data exploration and null value analysis  
- Year-wise and month-wise movie release trends  
- Genre analysis to identify most popular categories  
- Ranking of movies, actors, and directors using window functions (RANK)  
- Weighted average rating calculations based on votes  
- Analysis of production companies based on audience engagement  

---

## Key Insights
- Drama is the most dominant genre in terms of movie count  
- High-rated movies (>8 rating) are limited but driven by experienced directors and strong production houses  
- Optimal movie duration is around 100–110 minutes  
- Audience engagement (votes) is a strong indicator of movie success  
- March has the highest number of movie releases, indicating peak competition  

---

## Recommendations
- Focus on high-performing genres like Drama or multi-genre films  
- Collaborate with top-rated directors and production houses  
- Cast actors with strong audience engagement and ratings  
- Optimize movie duration and avoid peak release periods  
- Leverage data insights for global market strategy  

---

## Learning Outcomes
- Improved SQL proficiency (joins, subqueries, aggregations, window functions)  
- Gained experience in real-world data analysis and business problem-solving  
- Developed ability to convert raw data into actionable insights  

---

## Conclusion
This project demonstrates how SQL can be used effectively for data analysis and decision-making in the entertainment industry, helping businesses make strategic, data-driven choices.
